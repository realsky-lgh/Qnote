# Qnote (羽笺速记纸) ✦

> 专为捕捉灵感而生的极简速记纸。
> 从安装、使用到界面皆是极简。即开即记，丝滑手绘与文字兼备，随用随走。

---

## 🎨 特色与设计哲学

1. **呼之即来，挥之即去**：
   - 全局**双击 `Alt` 键**，瞬间呼出一小页轻盈、纯净的拟真笔记纸，光标默认落在纸上，不碰鼠标直接打字。
   - 再次双击 `Alt` 或按 `Esc`，便签纸像折叠收回口袋一样优雅隐退，安静常驻托盘，不占屏幕任何多余空间。

2. **双击 `~` 键：随心切换键盘输入与老手级涂鸦**：
   - 无论何时，在纸上连续按两次 `~`（反引号键）：
     - **键盘模式**：光标闪烁，畅快打字排版；
     - **涂鸦模式**：鼠标化身素描铅笔，自由比比划划、圈画草图、架构勾勒；
   - **像画画老手一样丝滑**：
     - 采用**中点二次贝塞尔样条插值 (Midpoint Quadratic Bezier Splines)**；
     - 内置微颤动滤波降噪与速度感知动态笔锋（快速提笔微收，沉着慢笔墨饱）；
     - 墨迹为纯正深玄墨黑（接近纯黑，有呼吸感，绝无毛刺锯齿）；
     - 支持 `Ctrl+Z` 撤销或右键一笔撤销。

3. **10 款最艺术、最适合眼睛的纸张底纹（随心切换）**：
   每一张纸都经过色温与视疲劳深度调优：
   - **暖玉柔光 (Warm Ivory)**：3800K 暖象牙漫反射柔光，过滤蓝光刺激，久看舒适。
   - **复古羊皮卷 (Aged Parchment)**：古典中世纪羊皮手稿，温厚暗角，文学质感。
   - **东方生宣 (Calligraphy Xuan)**：安徽宣纸微润质感与深沉墨韵。
   - **日式和纸 (Japanese Washi)**：天然植物轻柔纤维与极简禅意。
   - **手作牛皮纸 (Artisan Kraft)**：暖金工坊牛皮纸，灵感草图速写首选。
   - **极简点阵纸 (Dot Grid)**：22px 隐形淡灰圆点阵列，排版手绘两相宜。
   - **薄荷晨曦 (Morning Mint)**：清晨薄荷浅青绿底色 + 5mm 舒目微方格，缓解眼肌紧张。
   - **冷压水彩纸 (Cold-Pressed Watercolor)**：手工棉浆凹凸压纹颗粒，手绘微阻尼质感。
   - **打字机信笺 (Vintage Typewriter)**：复古浅蓝横格与淡红页边距线，诗意速记。
   - **竹炭墨石 (Charcoal Slate - 暗夜模式)**：深灰碳素石板极夜护眼纸，非刺眼死黑，配月影白墨。
   *(支持按顶部「纸张」面板挑选，或快捷键 `Ctrl+P` / `Alt+P` 一键轮换)*

4. **随时换新纸，写过全记住**：
   - 按 `Ctrl+N` 或点击「＋新纸」：当前页面立即入库封存，呈上一张干干净净的全新纸张。
   - **存储极简纯净**：
     - 不会为每张纸生成乱七八糟的碎片散落文件；
     - 不使用笨重的后台数据库服务，采用纯轻量嵌入式单文件 SQLite (`qnote.db`)，零配置零负担；
     - 每次敲字或划线后 400ms 自动静默持久化，断电防丢；
   - **回头慢慢整理**：按 `PageUp` / `PageDown` 或顶部「◀」「▶」即可随时像翻便签本一样回看与整理历史速记。

## ⚡ 极简安装与使用

本项目同时支持主流 **Linux** (Ubuntu, Fedora, Arch, Debian 等) 和 **Windows** (Win 10 / Win 11)。

### 📦 方式一：直接下载开箱即用二进制版本 (推荐，免装 Python)

- 前往项目的 **[Releases 页面](https://github.com/realsky-lgh/Qnote/releases)** 即可直接下载：
  - **Windows**：下载 `Qnote-windows-x64.zip`，解压后双击 `Qnote.exe` 即可直接运行！
  - **Linux**：下载 `Qnote-linux-x86_64.tar.gz`，解压后运行 `./qnote` 即可！

---

### 🐧 方式二：Linux 源码/脚本一键安装

#### 一键安装与开机自启
```bash
git clone https://github.com/realsky-lgh/Qnote.git
cd Qnote
./install.sh
```
安装后：
- 在任何终端输入 `qnote` 即可启动。
- **已默认配置开机自动启动**（登录系统后自动在后台静默就绪，不抢占焦点）。
- 系统托盘菜单提供「开机自动启动」选项，可随时一键勾选或取消。
- 全局双击 `Alt` 随时呼出 / 隐藏。
- 自动生成桌面应用图标。

#### 免安装启动
```bash
./run.sh
```

#### 本地自行打包二进制
```bash
./build_linux.sh  # 产物生成在 dist/qnote-linux-x86_64
```

---

### 🪟 方式三：Windows 源码/脚本运行

1. 双击运行目录下的 `run.bat`（自动静默准备环境并启动）。
2. 本地一键打包为单文件 `Qnote.exe`：双击 `build_windows.bat` 即可在 `dist\` 目录生成独立可执行程序。
3. 或在命令行直接运行：
```cmd
pip install PyQt6 pynput
pythonw main.py
```

## ⌨️ 快捷键指南

| 快捷键 | 功能 | 说明 |
| :--- | :--- | :--- |
| **双击 `Alt` 键** | **呼出 / 隐藏速记纸** | 全局有效，呼出后光标立刻就绪 |
| **连按两次 `~` 键** | **切换画画 / 打字** | 在当前纸张快速切换「文字输入」与「丝滑涂鸦」 |
| **`Ctrl + N`** | **换一张新纸** | 归档当前笔记，展开一张全新干净纸张 |
| **`Ctrl + P` / `Alt + P`**| **切换纸张底纹** | 在 10 款艺术护眼纸张中随心轮换 |
| **`PageUp` / `PageDown`** | **翻看历史纸张** | 浏览上一页、下一页历史草稿与涂鸦 |
| **`Ctrl + Z`** | **涂鸦撤销** | 涂鸦模式下撤销上一笔（亦可右键单击撤销） |
| **`Esc`** | **收入口袋** | 暂存并隐藏纸张 |

---

## 📂 数据存储位置

- **Linux**：`~/.config/qnote/qnote.db`
- **Windows**：`%APPDATA%\qnote\qnote.db`

整个软件所有纸张、文字与笔迹仅存于这唯一的单文件中，无需任何安装配置，备份只需复制单个 `.db` 文件。
